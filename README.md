# 🏓 Ping Pong Game

A mobile-friendly Ping Pong / Table Tennis game built with HTML5 Canvas and Capacitor.

## Features
- Player vs Computer
- First to 7 points
- Touch / mouse paddle control
- Arrow keys and W/S controls
- Mobile control buttons
- Pause and sound toggle
- Responsive game table
- Android APK GitHub Actions workflow

## Build APK
1. Upload this project to GitHub.
2. Go to **Actions**.
3. Select **Build Ping Pong APK**.
4. Click **Run workflow**.
5. Download the `Ping-Pong-APK` artifact.

No npm lockfile is required, so GitHub Actions uses `npm install` with caching disabled.
